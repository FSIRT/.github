### 🛋️ Das Wohnzimmer

**Raum 9-U09** ist unser Treffpunkt: Plätze zum Chillen, eine kleine Küche mit
Mikrowelle, Kaffeemaschine und Getränken, und Möglichkeiten zum gemeinsamen
Zocken. Tür offen heißt: reinkommen.

### 💾 Hier auf GitHub

In dieser Organisation liegt, was wir an Software für die Fakultät bauen —
vom Türsensor für 9-U09 bis zur Website. Offen, damit der Nächste den Code
findet und nicht bei null anfängt.

### 🎮 PixelCampus

Unser Minecraft-Server. Gemeinsam bauen, Abenteuer erleben, oder einfach
entspannt die virtuelle Welt erkunden.

### 🙋 Mitmachen

Der perfekte Einstieg ist eine unserer **Fachschaftssitzungen** — offen für
alle, ohne Anmeldung und ohne Vorwissen. Wer mehr will: es gibt Ämter für
Vorstand, Kasse, Marketing und Einkauf.

Für alles hier auf GitHub: kurz im [Discord](https://discord.gg/YupbSGd)
Bescheid sagen, damit niemand dasselbe doppelt anfängt. Fragen sind kein
Aufwand — ein halbfertiger Pull Request mit einer Frage dran ist uns lieber
als ein Projekt, das still liegen bleibt.
